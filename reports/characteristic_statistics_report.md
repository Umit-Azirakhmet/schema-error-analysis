## Cross-Dataset Notes

- **ARQA:** Active columns reflect evidence structure (paragraph/table refs, text spans, table-cell reference counts). DeepJSONEval schema-keyword columns are constant (all zero).
- **DeepJSONEval:** Active columns capture JSON Schema shape (primitive types, arrays, nesting depth, enums, property count). ARQA- and SchemaToJSON-specific flags are constant.
- **SchemaToJSON:** Only two unified columns vary (`table_cell_ref`, `long_text`). Most JSON-Schema-style features are zero because gold outputs use record-type schemas in `gold_json_records`, not JSON Schema objects.

### SchemaToJSON Sparsity Caveat

With only ~2 varying unified characteristics, SchemaToJSON error-correlation analysis against the full unified column set is limited. Future enrichment (e.g., record-type distribution, cell-count features) is recommended but out of scope for this report.
